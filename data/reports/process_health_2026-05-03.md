   Impact:  Potentially eliminates the entire proxy approximation cluster

   Pattern: The bundled mpc_q_lat change (entry 13) cost +82.5 pts across 4

   Action:  Before any commit that touches `_MPC_WEIGHT_AUTO_DERIVE_PARAMS`,

            require an E2E validation record (≥60s on highway_65 + one
            curve-heavy track) cited in the commit body. Add a pre-commit hook
            or CI step that detects numeric constant changes in these files and
            checks for the validation citation.
   Impact:  Prevents the most expensive failure class (implementation/testing
            misses on tuning changes). The one testing entry in the log was
            also the highest-deduction event — gate would have prevented it.

   Pattern: Two design bugs (entries 1 and 11) involved signals routed to the

            Run in Tier 1 (synthetic) comfort gate suite — no Unity required.
   Impact:  Converts post-hoc correlation diagnostics into pre-merge regression
            gates. Catches signal routing bugs at ~0 iteration cost vs the
            current 1–5 iteration detection delay.
