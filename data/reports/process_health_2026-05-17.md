## TOP 3 PROCESS IMPROVEMENTS

```
TOP 3 PROCESS IMPROVEMENTS
════════════════════════════════════════════════════════════════════════

1. PHYSICS-FIRST DESIGN GATE
   Pattern: 36% of all issues (5/14) stem from proxy approximation — a
            scalar or table substituting for a physics-derived formula.
            This cluster has the highest average detection delay (2.8 itr).
   Action:  Add a mandatory pre-implementation checklist item: "What
            physical quantity does this parameter approximate? Can we
            compute it directly?" Gate new parameters on dimensional
            analysis in design docs or commit message before any code is
            written. Examples: κ×v² for regime, time-to-curve for entry
            arm, forward velocity profile for speed planning.
   Impact:  Eliminates the largest root-cause cluster. Could prevent
            ~4 future issues of this type before they reach E2E.

2. E2E VALIDATION GATE FOR NUMERIC CHANGES
   Pattern: 1 entry (entry 13) cost +82.5 points across 4 tracks and
            invalidated 3 A/B runs because a 2-line tuning change was
            bundled without E2E validation.
   Action:  Pre-merge rule: any diff touching _MPC_WEIGHT_AUTO_DERIVE_PARAMS,
            av_stack_config.yaml tuning keys, or numeric constants in
            control/trajectory must include an E2E validation record
            (minimum 60s run on highway_65 + one curve-heavy track).
            Consider a pre-commit hook that detects numeric constant diffs
            in scoring-critical files and requires "--e2e-validated" in the
            commit message.
   Impact:  Prevents the highest-cost failure mode (82.5-point regression).
            Stops invalid A/B data from distorting subsequent tuning.

3. SIGNAL ROUTING CONTRACT TESTS
   Pattern: 2 entries (signal routing mis-alignment + term_time leak) and
            1 temporal coupling entry shared the same detection path:
            a trace tool revealed a signal going to the wrong destination.
            These were caught by tooling but only after 3-5 iterations.
   Action:  Add lightweight contract tests that assert key signal invariants
            without Unity:
            - corr(mpc_e_lat, -lateral_error) > 0.95 on curve segments
            - term_time == 0 on all straight-phase frames
            - control update rate >= 25 Hz independent of camera rate
            Run these on golden recordings in the existing pytest suite.
   Impact:  Converts 3-5 iteration detections into 0-iteration catches.
            Extends the existing comfort-gate test infrastructure without
            requiring new tooling investment.
```
