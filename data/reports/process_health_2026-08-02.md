## TOP 3 PROCESS IMPROVEMENTS

```
TOP 3 PROCESS IMPROVEMENTS
════════════════════════════════════════

1. Codify a physics-first design gate for all threshold parameters
   Pattern: 4 of 9 design bugs were proxy approximations — hand-tuned scalars
            standing in for derivable physical quantities.
   Action:  Add a design-review checklist item: "What physical quantity does this
            parameter approximate? Can we compute it directly?" Require dimensional
            analysis in PR description for any new threshold or table.
   Impact:  Prevents the entire proxy-approximation sub-category (44% of design
            failures), which was the single largest source of regressions.

2. Implement a phase-gating code review rule for steering terms
   Pattern: 4 design bugs involved terms active outside their intended driving
            phase (FF on straights, term_time leaking globally, binary gates on
            continuous signals, entry-arm at wrong time).
   Action:  Code review checklist: every new steering contribution must declare
            its active phase and have a gating assertion. Add a linting rule or
            test that asserts term contributions are zero outside their phase for
            recorded segments.
   Impact:  Closes the signal-routing + state-discretization + missing-state-machine
            sub-categories (3 of 9 design bugs share this root cause).

3. Formalize the E2E validation gate for tuning diffs
   Pattern: The largest single regression (entry 13: +82.5 pts lost, 4 tracks)
            was an undocumented numeric constant bundled in a feature commit.
            A pre-merge E2E gate would have caught it at cost of 1 run.
   Action:  Add a pre-commit or CI step: if `git diff` touches any key in
            `_MPC_WEIGHT_AUTO_DERIVE_PARAMS` or `config/av_stack_config.yaml`
            tuning blocks, require an `# e2e-validated` marker in the commit
            message (or fail the commit hook).
   Impact:  Directly prevents the testing/missing-coverage failure mode.
            Given that 1 missed E2E gate cost 82.5 points across 4 tracks,
            the prevention ROI is extremely high.
```
